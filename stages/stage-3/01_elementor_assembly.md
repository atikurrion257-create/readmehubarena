# Stage 3 — Elementor Free assembly contract

This is an offline build specification, not an Elementor export or a working site. Use Hello Elementor child-theme chrome from Stage 2; no Pro or extra addon. All components are server-rendered or native Elementor Free widgets. No single HTML widget holding a whole page. Each Page File's numbered tree is the exact section and widget order; replace text widgets with the corresponding complete copy in that file, not this specification. Each top-level `Section` below is a Flexbox container at depth 1. Each `Column` is a nested Flexbox container at depth 2; all listed widgets sit directly in that column. If a section lists widgets without columns, place those widgets directly in the section. No additional containers; maximum depth 2 (≤3). Use native Heading, Text Editor, Button, Icon Box, Image, and Shortcode widgets as named; real search/archive behavior needs the server-side integration described in the relevant Page File. Footer and header are outside Elementor in the theme.

## Shared precise settings

- Every section: boxed width 1200px, horizontal padding 24px at 1440/1280, 16px at 768/390/360; vertical padding 48px desktop, 32px at 768 and 24px at 390/360; gap 24px desktop, 16px otherwise. Reading column max 720px. Use Stage 2 palette and fonts; orange buttons dark text. Place one H1 in main; H2 section labels and H3 card/question labels. Maintain semantic reading order and 48px touch targets, visible focus and 200% reflow.
- `C1`: one full-width column at every viewport. `C2`: two 50% columns at 1440/1280/768, one 100% column at 390/360. `C3`: three equal columns at 1440/1280, two columns at 768 (last wraps), one at 390/360. Gap is included in flex sizing; never overflow.
- Each dynamic, shortcode, ACF/dynamic-tag or date/geo widget: **Advanced → Cache Settings = Inactive**, independent of global Element Caching. Marked `D` in each tree. Static widgets use inherited cache behavior. Shortcodes are literal and configured as shown in Page Files; verify plugin activation. Do not add duplicate visible empty states outside dynamic components: text labeled implementation/conditional is only displayed in the corresponding state, not alongside populated output.
- Images: no fabricated logo/hero asset. Homepage hero is text-only, so no LCP image to prioritize; if a real approved LCP image is later added, use its actual URL, dimensions, alt text and `fetchpriority="high"`; below-fold images lazy load with dimensions. Do not use Elementor custom attributes requiring Pro as a workaround.
- Links in the copy represent the final registry; suppress links to unpublished destinations in staging and production, and do not expose drafts. Retain link labels as plain text until destination publishes. Never manufacture a child to satisfy a hub. Child lists must reflect all actually published children, including later additions. Homepage matrix currently cannot show anything without at least two verified product records: omit the shortcode until suitable records exist and show the specified empty state. Never configure CTA column without first-link disclosure.
- Draft/noindex and sitemap gates apply to empty hubs and archives, directory until three published tools, and deals until at least one verified deal. Search and 404 always noindex; the 404 must send HTTP 404. Live publication, renderer, query, schema, canonical, sitemap, accessibility and mobile behavior require real staging QA. No implementation or frontend tests have occurred.
