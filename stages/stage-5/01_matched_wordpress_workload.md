# Stage 5A — Matched WordPress workload and evidence rules

**Research protocol, not a completed benchmark.** Apply this same hypothetical scenario and the same criteria to Kinsta, WP Engine, Cloudways, SiteGround and Hostinger. No test, account, price quote, speed, uptime or numerical score is asserted.

## Scenario and controls

One small-business WordPress site with a content section, contact form, ordinary media library and a small number of authorized editors; also evaluate whether a prospective store would need different resources. No fixed traffic, software version, plugin set, storage size, visitor geography or performance target is invented. Before a real comparison, the owner must supply and record identical representative inputs: WordPress/PHP versions; site content and database size; active theme and plugins; location; cache/CDN settings; access roles; visitor workload; sample business transaction; test window; and a budget. Use synthetic or authorized data.

## Matched research criteria

1. **Plan fit and limits:** same number of sites and required storage, bandwidth or visits; identify whether limits are hard caps, estimates, fair use or overage triggers.
2. **Operations:** WordPress updates, staging, backup frequency/retention and whether restoration is included; distinguish host responsibilities from the site owner's.
3. **Support and security:** included channel and scope; access roles, SSL, protection and response process as documented, not assumed service quality.
4. **Migration and recovery:** migration assistance, DNS/domain responsibility, export, rollback and ability to restore a representative backup. Validate conditions on the same selected plan.
5. **Total cost:** same currency, geography and site requirements; separately document introductory amount and term, renewal amount and term, taxes, domain, add-ons and overages. Where missing, use a verification token; no extrapolated total.
6. **Performance:** no winner without a repeatable controlled measurement and dated evidence. Report configuration, location, workload, raw data and limitations if later tested. Vendor marketing numbers are not benchmarks.

Use the official sources listed in each Page File and source audit. Unmatched capacity or missing conditions are explicitly unknown, not scored as a win. A plan is a research candidate only; skip it if a required feature or cost cannot be confirmed. A future test must cover each host with the same workload or clearly label non-comparable evidence. Follow the Stage 4 Mode B checklist with host-specific dated logs and screenshots; no worksheet has been completed for these hosts.
