# GitHub Pages design preview

This folder is a static, non-commercial visual concept, not a deployed WordPress site. GitHub Pages cannot execute PHP, WordPress, ACF, Elementor, or the Stage 6 importer. There are no reviews, real affiliate links, forms, or dynamically loaded content here. The Stage 7 BLOCK PUBLISH decision remains in force for the actual site and its drafts. `noindex` and robots instructions are requests to search crawlers, not access controls; GitHub Pages is publicly accessible.

GitHub Pages may be configured to deploy this branch's `/docs` folder. All page assets use relative URLs and work at a repository subpath. Open `index.html` directly or serve this folder over HTTP for a local preview. For staging WordPress setup, see `../stages/stage-6/bundle/README.md`.
