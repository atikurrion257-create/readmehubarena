# ReadMeHub project

This repository contains the offline ReadMeHub build and QA deliverables under `stages/` and a **static design preview** in [`docs/`](docs/). The preview can be hosted on GitHub Pages from the `/docs` folder and uses relative assets for repository subpaths.

The preview is not the WordPress website: GitHub Pages does not run PHP, Elementor, ACF, or the draft importer. No live reviews, affiliate links, forms, or dynamic site functionality are provided. It is public when hosted; its noindex directive is not access control.

Start with the [Stage 7 release gate](stages/stage-7/00_STAGE_7_STATUS.md) and the [Stage 6 offline staging bundle guide](stages/stage-6/bundle/README.md). **The actual website remains BLOCK PUBLISH** pending staging, evidence, legal and other QA requirements.
